## Overview

A production-ready DevSecOps pipeline-as-code demonstrating how to integrate automated security checks into CI/CD. This repository contains a fully functional GitHub Actions workflow that runs secret scanning, SAST, dependency/container scanning, and IaC checks on every push and pull request.

The project includes a deliberately vulnerable sample application so the pipeline produces realistic findings for demonstration and testing.

## Run locally (Docker shortcuts)
```bash
# gitleaks
docker run --rm -v "$PWD:/pwd" zricethezav/gitleaks:latest detect --source=/pwd -c .gitleaks.toml

# semgrep
docker run --rm -v "$PWD:/src" returntocorp/semgrep semgrep scan --config auto --config .semgrep.yml /src

# trivy fs
docker run --rm -v "$PWD:/work" aquasec/trivy:latest fs /work

# tfsec
docker run --rm -v "$PWD:/src" aquasec/tfsec:latest /src
```

## Configuration
- .gitleaks.toml — configure secrets patterns and allowlists
- .semgrep.yml — Semgrep rules and custom rulepacks
- trivy/.trivyignore — CVE ignore list for local testing
- tfsec/ — tfsec config and suppressions
